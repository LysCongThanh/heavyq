Exploration has run its course. Time to commit to something and learn from reality.

## Do now
- Pick one option. Write the reason in a single sentence; do not keep the others open "just in case".
- Define the smallest change that could prove the item is done, and make only that change.
- Run the gate and read the real result before deciding anything else.
- Park every other idea in a note. Do not act on it in this pass.

## Rules
- No new research, no new branches, no refactors on the side.
- A failed proof is information: adjust the same option once, then reassess.
