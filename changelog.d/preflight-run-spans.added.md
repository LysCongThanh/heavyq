**`heavyq preflight` and run spans.** Before a long unattended run, `heavyq preflight [--hours N] [--parallel N] [--json]` answers GO or NO-GO and lists, numbered, what a human must answer or fix now, each line ending with the command that fixes it: a goal and items with runnable proofs (and known durations), `after:` and `needs:`, disk, remotes, slots and pools, commands that would prompt in Claude Code (it reads the allow rules and follows the PreToolUse hook's rewrite), and quota headroom. A GO (or `--start`) opens a run span; `heavyq run end|ls|current` manage them, and a long session with no span gets one `next: heavyq preflight` line in the SessionStart brief. See [docs/preflight.md](docs/preflight.md).
