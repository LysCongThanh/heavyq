**Agent work trees inside the repository no longer make the main checkout unprovable.** Claude Code puts the work trees of its agents in `.claude/worktrees/` under the repository, and while they held changes every proof on the main checkout failed with "tree unknown". The tree identity now leaves out `.claude/worktrees/` and every untracked directory that holds its own `.git` (a linked work tree or another repository); a submodule recorded in the index still counts. `heavyq doctor` and `heavyq init` print the one line that also hides the folder from `git status` (`echo '.claude/worktrees/' >> "$(git rev-parse --git-path info/exclude)"`). See [docs/gates.md](docs/gates.md#what-the-tree-id-ignores).
