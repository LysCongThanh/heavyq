**A newer user config no longer bricks an older heavyq.** An unknown key in `~/.config/heavyq/config.toml` (a new section or a new key in a known one) used to make every command fail, including the `go build` that would have upgraded the binary. It now prints one warning on stderr and is ignored; `heavyq doctor` lists the keys with their lines and also says when the config does not load at all. The repository `heavyq.toml` stays strict, and so do wrong values and upper-case keys that would merge with a known one. See [docs/configuration.md](docs/configuration.md).
