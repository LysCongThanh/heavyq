**`heavyq statusline`, `heavyq recap`, a forecast and local notices.** Know when the work will finish and whether it is on track, without asking. `heavyq statusline` prints a segment for Claude Code's status line from the materialised flow state in under 5 ms and without running git (`◆ 5/8 proven  ⚑ 1 needs you  ▲ CI wait  ✓ on track · ~16:40`, nearly silent when nothing is notable); `--wrap '<your command>'` appends it to an existing status line without editing it. `heavyq recap [--since 2h|--session S|--run ID|--json]` is one screen: progress, forecast, the constraint, the one best next action, then merged-proven, proven, claimed-unproven, blocked, wasted (the same failure repeated) and in-flight, each line ending with the command that acts on it. The ETA is remaining items × the recent p50 claim-to-proof ÷ running lanes, `unknown` until three proofs are measured, `at risk` when it passes the run's expected end or nothing has been proven for twice the p50. A change that needs you, an at-risk forecast and all items proven each push one local notice (`notify-send`, `osascript`, OSC 9/777 or the bell), once per state change, at most 5 a day. See [docs/statusline.md](docs/statusline.md) and [docs/recap.md](docs/recap.md).
