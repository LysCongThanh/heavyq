**A guide to long runs that report themselves.** [docs/long-runs.md](docs/long-runs.md) is the 10-minute path for one engineer running Claude Code agents on a long run: install the hooks and the statusline, write the anchor and gates, run `heavyq preflight`, have agents claim and prove items, watch the run (statusline, `heavyq top`, `flow show`), then read `heavyq recap --run`. It also lists the known v0.5 limits and their workarounds.
