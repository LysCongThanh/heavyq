**`proof: gate:<name>` is the recommended proof form.** A shell-string proof can only be run as `heavyq ... -- sh -c '...'`, which a harness that vets commands (a subagent's worktree guard) refuses. `heavyq preflight` now warns when an item's proof needs a shell (a pipe, quotes) and suggests a gate; `gate run <name> --remote <r>` runs it without typing `sh -c`; this repository's own anchor proofs are now gates of its `heavyq.toml`. See [docs/gates.md](docs/gates.md#gates-as-the-proof-of-an-item). (#123)
