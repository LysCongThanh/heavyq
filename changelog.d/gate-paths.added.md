**A gate can declare `paths`, so a docs-only commit keeps its proof.** `paths = ["**/*.go", "go.mod", "go.sum"]` in a `[[gate]]` makes the gate's proof the content of the files those globs name instead of the whole tree: a commit or an uncommitted edit that touches none of them (a changelog, the docs, the anchor) leaves the gate proven, `gate run` runs nothing, and an item resting on `gate:<name>` is not made `stale`; a change to a listed file, or to the list, voids it. The gate's tree id is `paths-<digest>` in `gate status`, the ledger and its `run_id`. Patterns that match no committed file prove nothing (a typo cannot make a gate that is proven forever), and invalid patterns are refused at load. Without `paths` nothing changes. See [docs/gates.md](docs/gates.md#a-gate-with-paths).
